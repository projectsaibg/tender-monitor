1. What is Tender Monitor?

Tender Monitor is a small application that runs on your own Windows computer and watches government e-procurement / tender websites for you. You tell it which websites to watch and what words you care about (for example water, pipeline, WTP, STP); it visits those sites on a schedule, finds the tenders, and tells you which ones are new or changed since last time.

It can:

  • Monitor any number of public tender portals (NIC eProcurement portals like wbtenders.gov.in are supported automatically).
  • Detect NEW and UPDATED tenders (e.g. a closing date extended).
  • Download publicly available tender documents (NIT, BOQ, corrigendum, etc.).
  • Score tenders by relevance to your keywords (HIGH / MEDIUM / LOW).
  • Produce a professional Excel report and keep a full local history.
  • Run automatically every day, even when the window is closed.
Everything stays on your computer. There is no website to sign up for and no cloud account. The app opens in your normal web browser at http://127.0.0.1:8000, which is just your own machine.

2. Before you begin (what you need)

  • A computer with Windows 10 or 11.
  • Python 3.12 or newer (a free program the app is built on).
  • About 300 MB of free disk space.
  • An internet connection (to reach the tender websites you monitor).

Check if you already have Python

Open the Start menu, type cmd, open Command Prompt, type this and press Enter:

python --version

If it shows Python 3.12 (or higher), you are ready. If it says Python is not found, install it first:

  1. Go to https://www.python.org/downloads/ and download the latest Windows installer.
  2. Run the installer and - very important - tick "Add Python to PATH" at the bottom of the first screen.
  3. Click Install Now and wait for it to finish.
Don't skip "Add Python to PATH". If you forget it, the install step below will not be able to find Python. You can re-run the Python installer and tick it if needed.

3. Step 1 - Install the application

You should have a folder for the app, for example D:\Tender Monitor, containing files such as install.bat and start.bat.

  1. Open that folder in File Explorer.
  2. Double-click install.bat.
  3. A black window opens and sets everything up automatically. It will: create a private workspace, download the parts it needs, install a built-in browser it uses to read websites, and prepare the database.
  4. This takes a few minutes the first time. When you see "Installation complete", press a key to close the window.
You only ever run install.bat once. After that you start the app with start.bat.

4. Step 2 - Start the application

  1. Double-click start.bat in the same folder.
  2. A black window opens (leave it open - that is the app running) and your web browser opens automatically at http://127.0.0.1:8000.
  3. You should see the Dashboard shown below.

The Dashboard - your home screen. This is what opens when you start the app.

To stop the app later: close the black window, or double-click stop.bat. To use the app again another day, just double-click start.bat.

5. Step 3 - Understand the Dashboard

The Dashboard gives you the big picture at a glance:

  • Configured Portals / Scanned OK / Need Attention - how many websites you watch and their health.
  • Total Tenders, New (latest), Updated (latest), Documents - what the app has found.
  • Last Successful Scan and Next Scheduled Scan.
  • Recent Scans, Recent Errors and Notifications panels.

The buttons at the top - Add Portal, Run All Now, View New Tenders, Download Excel, View Scan History, Settings - are shortcuts to everything you need. The blue bar at the very top (Dashboard, Portals, Tenders, Archive, Scan History, Settings) is the main menu, always available.

Good news for Indian government portals: most state tender sites (West Bengal, Goa, Odisha, and others ending in /nicgep/app) are recognised automatically. Just paste the site's main address - the app knows how to read their "Tenders by Organisation" pages.

7. Step 5 - Test the portal

Before saving, click Test Portal. The app opens the website with its built-in browser and checks whether it can read tenders from it. After a few seconds you get a result like this:

A successful Test Portal result for a NIC eProcurement site.

Look at Automation Readiness at the top:

ResultMeaning
SUPPORTED / GOODThe app can read this site. Save and scan it.
SUPPORTED (NIC eProcurement)Recognised government portal - it will scan via "Tenders by Organisation".
PARTIALLY SUPPORTEDSome fields may be missing, but it will still work.
CAPTCHA / LOGIN REQUIREDThe site is protected; the app will not (and should not) bypass it.
SITE UNAVAILABLE / BLOCKEDThe site could not be reached right now - try again later.
For NIC portals the individual date/ID rows are read from the real "Tenders by Organisation" pages during the test, so you will see Published date, Closing date and Organisation marked PASS. Then click Save Portal.

8. Step 6 - Run your first scan

You can scan any time - you do not have to wait for the schedule.

  • From the Dashboard, click Run All Now to scan every enabled portal, or
  • Go to Portals and click Scan next to one portal.

A NIC portal walks through each government department, so the first scan can take a few minutes. Watch progress on the Scan History page.

Scan History - every scan with how many tenders were found, new, updated and downloaded.

The very first scan of a portal is a "baseline". It records everything that is already there but does not flag it all as NEW (that would be thousands of old tenders). From the second scan onward, only genuinely new or changed tenders are flagged NEW / UPDATED.
Tidy tip: right after your first baseline scan, use Archive reviewed (see Step 9) to clear the old pile so that, going forward, your Tenders list only fills with genuinely new tenders.

9. Step 7 - View and filter tenders

Click Tenders in the top menu. This shows the tenders the app has found, with their Published and Closing dates, value, a relevance badge and a status (new / updated / existing).

The Tenders page. Use the filters and the quick-view buttons at the top.

The two most useful buttons, at the top:

  • New today - tenders the app first saw today. This is the fastest way to see "what came in since yesterday".
  • Published today - tenders whose official published date is today.

You can also filter by portal, keyword, organisation, location, status, relevance and a Published date range. To focus on the best matches, set Relevance = HIGH.

Filtering to only NEW tenders - your daily short-list.

10. Step 8 - Open a tender's details

Click any tender's title to see everything about it: full metadata, the source link, downloaded documents, and its change history (for example "CLOSING DATE EXTENDED" with the old and new dates).

A tender's detail page, including documents and change history.

11. Step 9 - Keep the list tidy with Archive

Over time the Tenders list grows. To keep it focused on what is current, move old or already-reviewed tenders to the Archive (nothing is deleted - archived tenders are just hidden from the main list and can be restored any time).

On the Tenders page, three buttons help:

ButtonWhat it does
Archive reviewedArchives all unchanged tenders, keeps NEW and UPDATED. Best for daily clean-up.
Archive allMoves everything in the active list to the Archive (a full clear).
Archive (per row)Archive one tender using the small button on its row.

Open the Archive page from the top menu to search old tenders and Restore any of them.

The Archive page - old tenders, searchable, with Restore.

Updates are never lost: if a tender you archived later changes (a corrigendum or new closing date), the next scan automatically brings it back into the active list so you notice it.

12. Step 10 - Download the Excel report

Click Download Excel (on the Dashboard or the Tenders page) to get a full report file named like Tender_Report_2026-09-14.xlsx. It contains ready-to-use sheets:

  • NEW TENDERS, UPDATED TENDERS, ALL ACTIVE TENDERS
  • CLOSING WITHIN 7 DAYS, CLOSING WITHIN 30 DAYS
  • DOCUMENT DOWNLOADS, PORTAL STATUS, SCAN SUMMARY, ERRORS

Headers are frozen, filters are on, and links to the tender pages and documents are clickable. Tip: in the NEW TENDERS sheet you can filter the Published column to today's date to see only today's fresh tenders.

13. Step 11 - Automatic daily scans

There are two ways to run scans automatically:

a) While the app is open

If a portal's Schedule is Daily (or Weekly), the app scans it at the set time as long as the app window is running. The Dashboard shows the Next Scheduled Scan.

b) Even when the app is closed (recommended)

Use Windows Task Scheduler so scans run in the background:

  1. Double-click setup_scheduler.bat in the app folder.
  2. Type the time you want (e.g. 07:00) and press Enter.
  3. It creates a daily Windows task named TenderMonitorDaily that scans all your portals - the app window does not need to be open.
If Windows asks for administrator permission, right-click setup_scheduler.bat and choose Run as administrator.

14. Step 12 - Settings (timezone & email)

Open Settings from the top menu.

Settings - timezone and optional email notifications.

  • Timezone - leave as Asia/Kolkata unless you are elsewhere. This controls what "today" means and the times shown.
  • Email notifications (optional) - if you want a daily summary emailed to you, fill in your email provider's SMTP details, tick Enable notifications, and choose when to send (only if new tenders, only high relevance, etc.). Leave blank if you do not want email - everything works without it.
Your settings and passwords are stored only on your computer and are never shown in the logs.

15. Handy tips

Clone a portal

To watch several state portals with the same keywords, set one up, then on the Portals page click Clone. It copies every setting into a new portal and opens it for editing - just change the Name and URL and Save.

Choosing good keywords

Keywords decide what counts as relevant. Use the words that appear in tender titles, e.g. for water works: water, pipeline, WTP, STP, JJM, sewerage, water treatment. Add Negative Keywords to remove noise, e.g. vehicle, security, canteen.

16. Your everyday routine

  1. Open the app (double-click start.bat) - or let the daily Windows task scan for you.
  2. Go to Tenders and click New today (optionally set Relevance = HIGH).
  3. Open any tender to read details and download its documents.
  4. Click Download Excel to save/share the report.
  5. Click Archive reviewed to clear what you have handled - tomorrow only new ones appear.
That is the whole daily loop: New today → review → Excel → Archive reviewed.

17. Troubleshooting

ProblemWhat to do
"Python was not found" during installInstall Python 3.12+ and tick "Add Python to PATH", then run install.bat again.
The browser page shows {"detail":"Not Found"} after an updateThe app needs a restart to load changes. Close the black window (or stop.bat) and run start.bat again.
A portal says CAPTCHA REQUIRED / LOGIN REQUIREDThat site is protected and cannot be automated. This is expected for some portals.
A site briefly shows an error or "503"The website is busy or blocking automated visits. Wait a while and scan again.
"Archive older/reviewed" seems to do nothingCheck the green message it shows - if everything is from today, there may be nothing unchanged to archive yet. Use "Archive all" to clear fully.
Port 8000 already in useAnother copy is running. Close all black windows and start again, or use a different port.
Where are my files?Inside the app folder: data\downloads (documents), data\reports (Excel), data\logs (logs).
